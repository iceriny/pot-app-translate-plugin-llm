# Manggo 原生 AI 翻译与词典 4.0.0-beta.1

这是原 Pot LLM 插件的 Manggo 原生迁移**预发布版**，与此前交付的 beta.1 测试包字节一致。源码和测试已提交到 `manggo` 分支，旧 Pot `main` 分支及历史保留。此次发布不将未经完整宿主验收的 beta 标记成稳定版。

## 下载与安装

下载本 Release 附件 `com.iceriny.llm-4.0.0-beta.1.mplugin`，不要选择 GitHub 自动生成的 Source code ZIP。

1. 在 Manggo「插件管理」安装 `.mplugin`
2. 到「翻译服务」添加「AI 翻译 · LLM」，配置服务商、API 密钥和模型
3. 如需原生词典卡片，另外添加「AI 词典 · LLM」，配置独立
4. 输入 `?` 可查看离线帮助

建议使用 **Manggo v1.0.2**；插件功能需要 **Pro**。未声明未经验证的更早最低版本。旧 Pot 配置与密钥不会自动迁移，请在服务设置中重新填写，不要把密钥提交到问题反馈中。

## 迁移与改进

- 使用 Bun/ESM 与 `manggo.plugin.v1` 原生协议、标准 Fetch 请求
- 真正增量 SSE 流式，处理 UTF-8 分片、不同换行、完成标记、断流和截断；不重复累加整段译文
- 密码控件、可编辑模型下拉、服务商预设、自定义兼容接口、本机 Ollama
- 术语表、补充要求、超时和 tokens 设置；不自动重试可能收费的请求
- 保留翻译、润色、发音、口语和问答指令，新增独立结构化 AI 词典
- 移除不可靠宿主历史缓存；错误不再作为成功译文返回，避免在错误中泄露密钥
- 安装包仅含**一个压缩 bundle main.js**、清单、图标和 GPL LICENSE，无源码模块、node_modules、sourcemap

## 验证范围

已通过：53 项 Node 测试、24 项 Python 打包测试、Bun 1.4.2 下 49 项源码/压缩协议测试，最终包独立导入与本地 HTTP/SSE/词典冒烟测试；重复构建一致。发布流程还会重新运行测试并核对已交付包的 SHA-256。

尚待实际验收：Manggo 宿主导入/界面、真实服务商账户与收费 API、代理及宿主取消表现。公开插件契约未提供宿主取消信号，本插件仅提供请求超时。词典释义和发音由 AI 生成，需要核对。
